Limits are counted **per client IP** (per account on routes that need a token) over a fixed window.
Two layers apply:

1. **Every endpoint: 300 requests per minute per IP.** A safety net against floods, generous enough for
   a whole office or classroom browsing the site from one network.
2. **Stricter limits on the endpoints that send email, store data or check a secret**, listed below.
   Each endpoint has its **own counter**: using up one form does not block another.

## Headers

Every response reports the budget of the tightest limit that applies:

```http
X-RateLimit-Limit: 5
X-RateLimit-Remaining: 4
```

On an endpoint without its own limit, that is the global one (`X-RateLimit-Limit: 300`).

## When you hit the limit

```http
HTTP/1.1 429 Too Many Requests
Retry-After: 42
X-RateLimit-Limit: 5
X-RateLimit-Remaining: 0
```

```json
{
  "message": "Too Many Attempts."
}
```

The message is not translated. On the public site, show a "try again in a minute" message for any
`429` instead of the raw text.
