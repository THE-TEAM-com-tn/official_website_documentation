---
title: "Track a réclamation"
sidebarTitle: "Track a réclamation"
description: "Look up a réclamation's status and the team's reply with its tracking code."
api: "GET /reclamation-submissions/{tracking}"
---

Backs the **Suivre** tab of the `/reclamation` page. The tracking code is normalised to uppercase and must
match `^[A-F0-9]{10}$`. The payload is **client-safe**: internal columns (id, client email, archive flag,
editor) are never returned.

Malformed and unknown codes both answer `404`, with different messages; treat them the same in the UI.
Because the code is the only credential, the route is limited to **20 requests per minute**.

<ParamField path="tracking" type="string" required>
  10-character tracking code, case-insensitive.
</ParamField>

## Response

<ResponseField name="tracking" type="string" required />
<ResponseField name="type" type="string" required>`refund`, `complaint`, `technical`, `billing` or `other`.</ResponseField>
<ResponseField name="type_label" type="string" required>Label in the request language (tables below).</ResponseField>
<ResponseField name="subject" type="string" required />
<ResponseField name="message" type="string" required />
<ResponseField name="status" type="string" required>`unchecked`, `processing`, `resolved` or `closed`.</ResponseField>
<ResponseField name="status_label" type="string" required>Label in the request language (table below).</ResponseField>
<ResponseField name="reply" type="string | null">The team's reply, once written.</ResponseField>
<ResponseField name="replied_at" type="string | null">ISO 8601, set whenever the reply changes.</ResponseField>
<ResponseField name="created_at" type="string" required>ISO 8601.</ResponseField>

| `status` | `status_label` (French, default) | `status_label` (`X-Locale: en`) |
| :-- | :-- | :-- |
| `unchecked` | En attente de traitement | Pending review |
| `processing` | En cours de traitement | In progress |
| `resolved` | Résolue | Resolved |
| `closed` | Clôturée | Closed |

The `404` messages follow the request language too (`No complaint matches this tracking number.` in English).

<RequestExample>

```bash cURL
curl "https://admin.theteam.com.tn/api/reclamation-submissions/9E9969EE97" \
  -H "Accept: application/json"
```

```javascript JavaScript
const code = input.trim().toUpperCase();
const res = await fetch(`https://admin.theteam.com.tn/api/reclamation-submissions/${encodeURIComponent(code)}`, {
  headers: { Accept: "application/json" },
});
if (res.status === 404) return showUnknownCode();
const reclamation = await res.json();
```

</RequestExample>
