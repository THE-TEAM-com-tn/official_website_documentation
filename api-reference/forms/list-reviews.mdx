---
title: "List reviews"
sidebarTitle: "List reviews"
description: "Every submitted review, newest first, as a bare array."
api: "GET /review-submissions"
---

Returns **all** reviews, newest first, without pagination or moderation filter.

<Warning>
  The payload includes each reviewer's **email** and **phone** as submitted, and the endpoint is public.
  Do not display those fields, and consider them exposed.
</Warning>

## Response

An array of reviews:

<ResponseField name="id" type="integer" required />
<ResponseField name="name" type="string" required />
<ResponseField name="email" type="string | null" />
<ResponseField name="phone" type="string | null" />
<ResponseField name="rating" type="integer" required>1 to 5.</ResponseField>
<ResponseField name="subject" type="string | null">`elearning`, `formation`, `entreprise`, or `null` for older reviews.</ResponseField>
<ResponseField name="comment" type="string" required />
<ResponseField name="created_at" type="string" required />
<ResponseField name="updated_at" type="string" required />
<ResponseField name="subject_label" type="string | null">French label of `subject`.</ResponseField>

<RequestExample>

```bash cURL
curl "https://admin.theteam.com.tn/api/review-submissions" \
  -H "Accept: application/json"
```

```javascript JavaScript
const res = await fetch("https://admin.theteam.com.tn/api/review-submissions", {
  headers: { Accept: "application/json" },
});
const reviews = await res.json();
```

</RequestExample>
