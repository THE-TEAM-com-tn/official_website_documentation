Base URL: `https://admin.theteam.com.tn/api`. Send `Accept: application/json` on every request.
"Bearer" marks the endpoints that need a [staff token](/concepts/authentication); limits are per IP or per
account (see [Rate limits](/concepts/rate-limits)).

<Info>
  The interactive playground is enabled on read endpoints only. Write endpoints show a copyable request
  instead, because the server is production: test them against a
  [local backend](/quickstart#run-the-backend-locally).
</Info>

## Not part of the API

- **`POST /api/register`** was removed on 2026-11-04 and answers `404`: staff accounts come from the admin panel.
- **`/api/import`, `/api/export`, `/api/export/{id}`** were removed on 2026-10-02. JSON import and export of
  blog posts, articles and trainings are admin-panel features.
- **The admin panel (`/admin`)** uses session authentication and HTML/Inertia responses. It is not a JSON API.
