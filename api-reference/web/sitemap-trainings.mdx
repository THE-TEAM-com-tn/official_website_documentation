A [sitemaps.org](https://www.sitemaps.org/protocol.html) `urlset` with one entry per **published**
training, pointing at the site's course page `https://theteam.com.tn/course/{slug}`, with `hreflang`
alternates for the `/en/` URL. `lastmod` is the training's last update.

The static site cannot list the catalogue itself, so the backend generates this file and serves it from this
host. The site's `robots.txt` lists it **by this URL**: search engines accept a sitemap on another host when
the site's own `robots.txt` points at it, so no proxy is needed. This host's `robots.txt` allows the file,
and the response carries `X-Robots-Tag: noindex` without `nofollow`: the XML stays out of search results
while the URLs it lists are followed (see [Crawlers](/api-reference/system/overview#crawlers)).

The same published trainings are pre-rendered as full HTML pages when the site is built, so every URL of
this sitemap also has a page crawlers can read without JavaScript (see
[Pre-rendered pages](/concepts/publishing-and-caching#pre-rendered-pages-on-the-public-site)).

Served as `application/xml; charset=UTF-8` with `Cache-Control: public, max-age=300` and
`X-Robots-Tag: noindex`, and cached by the
[training catalogue cache](/concepts/publishing-and-caching#training-catalogue-cache).

<RequestExample>

```bash cURL
curl "https://admin.theteam.com.tn/sitemap-trainings.xml"
```

</RequestExample>

<ResponseExample>

```xml 200
<?xml version="1.0" encoding="UTF-8"?>
<urlset xmlns="http://www.sitemaps.org/schemas/sitemap/0.9" xmlns:xhtml="http://www.w3.org/1999/xhtml">
  <url>
    <loc>https://theteam.com.tn/course/formation-ba-par-la-pratique</loc>
    <lastmod>2025-12-24</lastmod>
    <changefreq>monthly</changefreq>
    <priority>0.8</priority>
    <xhtml:link rel="alternate" hreflang="fr" href="https://theteam.com.tn/course/formation-ba-par-la-pratique"/>
    <xhtml:link rel="alternate" hreflang="en" href="https://theteam.com.tn/en/course/formation-ba-par-la-pratique"/>
  </url>
</urlset>
```

</ResponseExample>
