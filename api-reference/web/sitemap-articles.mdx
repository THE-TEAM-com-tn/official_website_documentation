---
title: "Articles sitemap"
sidebarTitle: "Articles sitemap"
description: "XML sitemap of every published Knowledge Corner article, with hreflang pairs and cover images."
api: "GET https://admin.theteam.com.tn/sitemap-articles.xml"
playground: "simple"
---

Lists every **published** Knowledge Corner article at `https://theteam.com.tn/{slug}`, plus its
`/en/{slug}` URL **only when the article is translated**, with `hreflang` pairs (`fr`, `en`, `x-default`),
`lastmod` and the cover in `image:image`. Pinned articles get priority `1.0`, others `0.8`.

Like the [trainings sitemap](/api-reference/web/sitemap-trainings), the site's `robots.txt` lists it by this
URL, this host's `robots.txt` allows it, and it is sent with `X-Robots-Tag: noindex` without `nofollow`.

The XML is cached for **10 minutes** and the cache is cleared on every article write. Served with
`Cache-Control: public, max-age=600`.

<RequestExample>

```bash cURL
curl "https://admin.theteam.com.tn/sitemap-articles.xml"
```

</RequestExample>

<ResponseExample>

```xml 200
  <url>

    <xhtml:link rel="alternate" hreflang="en" href="https://theteam.com.tn/en/certification-pmp-version-8"/>
    <xhtml:link rel="alternate" hreflang="x-default" href="https://theteam.com.tn/certification-pmp-version-8"/>

    </image:image>
  </url>
</urlset>
```

</ResponseExample>
