playground: "simple"
---

The public site is a static SPA, so social crawlers (Facebook, LinkedIn, X, WhatsApp) never see the
per-post tags it sets in JavaScript. The site's share buttons therefore link here. This web route (outside
`/api`) returns an HTML page with the post's Open Graph and Twitter tags, and immediately redirects people
to `https://theteam.com.tn/blog/{slug}`.

- **Title:** `meta_title`, or the post title.
- **Description:** `meta_description`, or the first 200 characters of the content.
- **Image:** the post's cover.
- Unknown or unpublished slugs redirect (`302`) to `https://theteam.com.tn/blogs`.
- `?lang=en` renders the English title and description (French when untranslated). The redirect still
  targets the French URL `/blog/{slug}`; only the [article share page](/api-reference/web/share-article)
  redirects to `/en/`.

<ParamField path="slug" type="string" required>
  Blog post slug.
</ParamField>

<ParamField query="lang" type="string" default="fr">
  `fr` or `en`.
</ParamField>

<RequestExample>

```bash cURL
curl "https://admin.theteam.com.tn/share/blog/power-bi-en-tunisie-transformer-vos-donnees-en-decisions"
```

```html Share link
<a href="https://www.linkedin.com/sharing/share-offsite/?url=https%3A%2F%2Fadmin.theteam.com.tn%2Fshare%2Fblog%2Fpower-bi-en-tunisie-transformer-vos-donnees-en-decisions">

```

</RequestExample>
