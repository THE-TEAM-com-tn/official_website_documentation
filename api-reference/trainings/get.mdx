---
title: "Get a training"
sidebarTitle: "Get a training"
description: "Full training details by slug or id: pricing, certification, prerequisites, objectives and the modules with their lessons."
api: "GET /trainings/{idOrSlug}"
---

Powers the site's course page (`/course/{slug}`). The path accepts the **slug** or the numeric **id**:
a purely numeric value is looked up by id, anything else by slug. Slugs are unique and never rewritten
when a title changes, so old links keep working.

The payload is a **bare object** (no `data` wrapper) and is cached for 5 minutes per locale, like the
list. See [Publishing and caching](/concepts/publishing-and-caching).

<Warning>
  This endpoint does **not** filter on `visibility_status`: an unpublished training is returned if you
  know its slug or id. Check `visibility_status` before linking to a training you did not get from
  [List trainings](/api-reference/trainings/list).
</Warning>

<ParamField path="idOrSlug" type="string" required>
  Training slug (`formation-cpmai`) or id (`22`).
</ParamField>

<ParamField header="X-Locale" type="string" default="fr">
  `fr` or `en`.
</ParamField>

## Response

<ResponseField name="id" type="integer" required />
<ResponseField name="slug" type="string" required />
<ResponseField name="title" type="string" required>Translated.</ResponseField>
<ResponseField name="intro" type="string | null">Translated; admin-authored HTML or text.</ResponseField>
<ResponseField name="overview" type="string | null">Translated; admin-authored HTML or text.</ResponseField>
<ResponseField name="duration_label" type="string | null">Translated, for example `24h`.</ResponseField>
<ResponseField name="price" type="string | null">Decimal as a string, for example `"0.00"`.</ResponseField>
<ResponseField name="visibility_status" type="string" required>`published` for catalogue trainings.</ResponseField>
<ResponseField name="is_pinned" type="boolean" required />
<ResponseField name="featured_image_url" type="string" required>
  Absolute URL, never `null` (falls back to the shared placeholder image).
</ResponseField>
<ResponseField name="badge_image_url" type="string | null">Certification badge image, if uploaded.</ResponseField>
<ResponseField name="certification" type="object" required>
  `{ name, url }`, both nullable. `name` is translated.
</ResponseField>
<ResponseField name="prerequisites" type="string | null">
  Free text as typed in the admin, line breaks preserved. Render it as prose, not as a split list.
</ResponseField>
<ResponseField name="learning_objectives" type="string | null">Free text, same rules as `prerequisites`.</ResponseField>
<ResponseField name="elearning_unlocked" type="boolean" required>
  `true`: buying the training grants lifetime e-learning access, recorded sessions included. `false`:
  lifetime access to the training resources (PDF, slides) only.
</ResponseField>
<ResponseField name="quizzes_count" type="integer | null" />
<ResponseField name="included_resource" type="object" required>
  `{ label, url }`, both nullable. `label` is translated.
</ResponseField>
<ResponseField name="modules" type="object[]" required>
  Ordered by `position`.

  <Expandable title="module">
    <ResponseField name="id" type="integer" required />
    <ResponseField name="title" type="string" required>Translated.</ResponseField>
    <ResponseField name="summary" type="string | null">Translated.</ResponseField>
    <ResponseField name="position" type="integer" required />
    <ResponseField name="lessons" type="object[]" required>
      `{ id, title, position }`, ordered by `position`; `title` is translated. Can be empty.
    </ResponseField>
  </Expandable>
</ResponseField>
<ResponseField name="categories" type="object[]" required>`{ id, name }`.</ResponseField>
<ResponseField name="created_at" type="string" required>ISO 8601.</ResponseField>
<ResponseField name="updated_at" type="string" required>ISO 8601.</ResponseField>

<RequestExample>

```bash cURL
curl "https://admin.theteam.com.tn/api/trainings/formation-cpmai" \
  -H "Accept: application/json"
```

```javascript JavaScript
const res = await fetch("https://admin.theteam.com.tn/api/trainings/formation-cpmai", {
  headers: { Accept: "application/json", "X-Locale": "fr" },
});
if (res.status === 404) throw new Error("Training not found");
const training = await res.json();
```

</RequestExample>
