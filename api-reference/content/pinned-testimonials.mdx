---

Returns exactly the same bare array as [List testimonials](/api-reference/content/list-testimonials):
"pinned" and "published" are the same flag. Prefer `GET /testimonials` in new code.

<ParamField header="X-Locale" type="string" default="fr">
  `fr` or `en`.
</ParamField>

<RequestExample>

```bash cURL
curl "https://admin.theteam.com.tn/api/testimonials/pinned" \
  -H "Accept: application/json"
```

```javascript JavaScript
const res = await fetch("https://admin.theteam.com.tn/api/testimonials/pinned", {
  headers: { Accept: "application/json" },
});
const testimonials = await res.json();
```

</RequestExample>
