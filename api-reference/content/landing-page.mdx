---
title: "Get the landing page"
sidebarTitle: "Landing page"
description: "The home-page singleton with its staff, partner companies, carousel, featured categories and published testimonials."
api: "GET /landing-page"
---

Returns the site-wide settings record wrapped in `landing_page`. The public site fetches it **once per
visit** and shares it across the home page, header, footer, calendar and 404 page, so it carries more than
the home page: company details, footer contacts and social links, section toggles, the promo strip and the
mobile-app links.

The record is serialized as stored, with its relations. The internal team-inbox address
(`notification_email`) is always removed.

<ParamField header="X-Locale" type="string" default="fr">
  `fr` or `en`. Translatable texts (company description, header and banner texts, promo strip, staff
  titles, testimonial texts, partner descriptions and categories, slides, featured categories) follow it.
</ParamField>

## Response

<ResponseField name="landing_page" type="object" required>
  <Expandable title="company and header" defaultOpen>
    <ResponseField name="id" type="integer" required />
    <ResponseField name="company_name" type="string | null" />
    <ResponseField name="company_description" type="string | null">Translated.</ResponseField>
    <ResponseField name="company_logo" type="string | null">Stored path. Also `company_logo_dark`, `company_favicon`.</ResponseField>
    <ResponseField name="company_website" type="string | null" />
    <ResponseField name="header_title" type="string | null">Translated. Also `header_subtitle`, `header_description`.</ResponseField>
    <ResponseField name="header_registration_link" type="string | null" />
    <ResponseField name="header_url" type="string | null" />
    <ResponseField name="header_image" type="string | null">Also `header_background_image`.</ResponseField>
  </Expandable>

  <Expandable title="footer, apps and calendar">
    <ResponseField name="footer_address" type="string | null" />
    <ResponseField name="footer_phone_number" type="string | null">Also `footer_mobile_number`, `footer_whatsapp_number`.</ResponseField>
    <ResponseField name="footer_contact_email" type="string | null" />
    <ResponseField name="footer_gmaps_url" type="string | null" />
    <ResponseField name="footer_facebook_url" type="string | null">
      Also `footer_twitter_url`, `footer_linkedin_url`, `footer_instagram_url`, `footer_youtube_url`.
    </ResponseField>
    <ResponseField name="app_store_url" type="string | null">
      Mobile-app link. Empty means "not published yet": the site shows a coming-soon badge. Same for `play_store_url`.
    </ResponseField>
    <ResponseField name="goole_calendar_url" type="string | null">
      Embedded Google Calendar URL of the training sessions. The key is spelled `goole` in the database.
    </ResponseField>
  </Expandable>

  <Expandable title="banners and section toggles">
    <ResponseField name="banner_title" type="string | null">Translated. Also `banner_url`, `banner_image`.</ResponseField>
    <ResponseField name="promo_banner_body" type="string | null">
      Rich-text HTML of the top-of-page promo strip (links, bold, italic, underline). Translated.
    </ResponseField>
    <ResponseField name="show_promo_banner" type="boolean" required>
      The strip shows only when this is `true` **and** `promo_banner_body` is not empty. Defaults to `false`.
    </ResponseField>
    <ResponseField name="show_header_section" type="boolean">
      Also `show_facts_section`, `show_partners_section`, `show_testimonials_section`,
      `show_banner_section`, `show_link_section`. Some come back as `1`/`0` instead of booleans.
    </ResponseField>
  </Expandable>

  <Expandable title="relations">
    <ResponseField name="staff_members" type="object[]" required>
      Team members: `name`, `title` (translated), `linkedin`, `position`, `staff_members_image` and the
      absolute `staff_members_image_url`.
    </ResponseField>
    <ResponseField name="partner_companies" type="object[]" required>
      Clients and partners: `name`, `description` (translated), `website_url`, `is_pinned`, `position`, the
      logo path and absolute `partner_companies_logo_url`, and `subcategory` (nullable) with its parent
      `category`. `subcategory.display_name` reads `Category › Sub-category`.
    </ResponseField>
    <ResponseField name="carousel_slides" type="object[]" required>
      `name`, `title`, `description`, `redirection_url`, `carousel_slide_image`, `position`.
    </ResponseField>
    <ResponseField name="featured_categories" type="object[]" required>
      `name`, `featured_category_icon`, `featured_category_image`, `position`.
    </ResponseField>
    <ResponseField name="testimonials" type="object[]" required>
      **Published** testimonials only, ordered by `position`, with `testimonial_image_url`.
    </ResponseField>
  </Expandable>
</ResponseField>

Every record also carries `created_at`, `updated_at` and, for uploaded images, a `*_file_id` column
(usually `null`).

<RequestExample>

```bash cURL
curl "https://admin.theteam.com.tn/api/landing-page" \
  -H "Accept: application/json"
```

```javascript JavaScript
const res = await fetch("https://admin.theteam.com.tn/api/landing-page", {
  headers: { Accept: "application/json", "X-Locale": "fr" },
});
const { landing_page } = await res.json();
```

</RequestExample>
