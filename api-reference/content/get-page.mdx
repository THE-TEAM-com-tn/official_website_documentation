---
title: "Get a page"
sidebarTitle: "Get a page"
description: "One CMS page by slug."
api: "GET /pages/{slug}"
---

Returns the page as a **bare object**, with the same fields as in [List pages](/api-reference/content/list-pages).

<Warning>
  This endpoint does not check `is_published`: an unpublished page is returned too. Check the flag before
  rendering it.
</Warning>

<ParamField path="slug" type="string" required>
  Page slug.
</ParamField>

<ParamField header="X-Locale" type="string" default="fr">
  `fr` or `en`.
</ParamField>

<RequestExample>

```bash cURL
curl "https://admin.theteam.com.tn/api/pages/politique-de-confidentialite" \
  -H "Accept: application/json"
```

```javascript JavaScript
const res = await fetch(`https://admin.theteam.com.tn/api/pages/${encodeURIComponent(slug)}`, {
  headers: { Accept: "application/json" },
});
const page = await res.json();
if (!res.ok || !page.is_published) return notFound();
```

</RequestExample>
