api: "GET /menu/{id}"
---

Returns one top-level item wrapped in `data`, with the fields of [List menu items](/api-reference/content/list-menu).

<ParamField path="id" type="integer" required>
  Top-level menu item id.
</ParamField>

<ParamField header="X-Locale" type="string" default="fr">
  `fr` or `en`.
</ParamField>

<RequestExample>

```bash cURL
curl "https://admin.theteam.com.tn/api/menu/1" \
  -H "Accept: application/json" \
  -H "X-Locale: en"
```

```javascript JavaScript
const res = await fetch(`https://admin.theteam.com.tn/api/menu/${id}`, {
  headers: { Accept: "application/json", "X-Locale": "en" },
});
const { data: item } = await res.json();
```

</RequestExample>
