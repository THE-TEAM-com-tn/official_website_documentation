title: "List testimonials"

description: "Published testimonials, ordered by position, as a bare array."
api: "GET /testimonials"
---

Returns the **published** testimonials (`is_pinned = true`, shown as **Published** in the admin panel)
ordered by `position`, as a **bare JSON array**. Testimonials sent through
[Submit a testimonial](/api-reference/forms/submit-testimonial) stay hidden until staff publish them.

<ParamField header="X-Locale" type="string" default="fr">
  `fr` or `en`. `job_title` and `content` are translated.
</ParamField>

## Response

An array of testimonials:

<ResponseField name="id" type="integer" required />
<ResponseField name="name" type="string" required>Author name.</ResponseField>
<ResponseField name="job_title" type="string | null">Translated.</ResponseField>
<ResponseField name="content" type="string" required>Translated testimonial text.</ResponseField>
<ResponseField name="redirection_url" type="string | null">Author's LinkedIn profile or company page.</ResponseField>
<ResponseField name="is_pinned" type="boolean" required>Always `true` here.</ResponseField>
<ResponseField name="position" type="integer | null">Display order.</ResponseField>
<ResponseField name="testimonial_image_url" type="string | null">Absolute photo URL.</ResponseField>

<RequestExample>

```bash cURL
curl "https://admin.theteam.com.tn/api/testimonials" \
  -H "Accept: application/json"
```

```javascript JavaScript
const res = await fetch("https://admin.theteam.com.tn/api/testimonials", {
  headers: { Accept: "application/json" },
});
const testimonials = await res.json();
```

</RequestExample>
