---
title: "List pinned blog posts"
sidebarTitle: "Pinned posts"
description: "The three most recently updated pinned and published blog posts, in a slim shape."
api: "GET /blog-posts/is_pinned"
---

Returns up to **3** posts that are pinned **and** published, ordered by `updated_at`, newest first. The
items use a slimmer shape than the list: no content, tags or category.

## Response

<ResponseField name="data" type="object[]" required>
  <Expandable title="post" defaultOpen>
    <ResponseField name="id" type="integer" required />
    <ResponseField name="title" type="string" required>Translated.</ResponseField>
    <ResponseField name="slug" type="string" required />
    <ResponseField name="author_id" type="integer | null" />
    <ResponseField name="category_id" type="integer | null" />
    <ResponseField name="status" type="boolean" required />
    <ResponseField name="is_pinned" type="boolean" required />
    <ResponseField name="published_at" type="string" required>ISO 8601.</ResponseField>
    <ResponseField name="updated_at" type="string" required>ISO 8601.</ResponseField>
    <ResponseField name="image_url" type="string | null" />
    <ResponseField name="author" type="object | null">`{ id, name, email }`.</ResponseField>
  </Expandable>
</ResponseField>

<RequestExample>

```bash cURL
curl "https://admin.theteam.com.tn/api/blog-posts/is_pinned" \
  -H "Accept: application/json"
```

```javascript JavaScript
const res = await fetch("https://admin.theteam.com.tn/api/blog-posts/is_pinned", {
  headers: { Accept: "application/json" },
});
const { data: pinned } = await res.json();
```

</RequestExample>
