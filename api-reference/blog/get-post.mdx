---
title: "Get a blog post"
sidebarTitle: "Get a post"
description: "One published blog post by slug, with its full HTML content."
api: "GET /blog-posts/{slug}"
---

Looks the post up by **slug** (not id). The post must be published; drafts, deleted and unknown posts
answer `404`. The fields are the same as in [List blog posts](/api-reference/blog/list-posts), except
that `content` is the **full HTML body**.

Social networks should not be given the site's `/blog/{slug}` URL directly: share
[`/share/blog/{slug}`](/api-reference/web/share-blog), which serves real Open Graph tags.

<ParamField path="slug" type="string" required>
  Post slug, derived from the French title.
</ParamField>

<ParamField header="X-Locale" type="string" default="fr">
  `fr` or `en`. The slug is the same in both languages.
</ParamField>

## Response

<ResponseField name="data" type="object" required>
  A post object. See [List blog posts](/api-reference/blog/list-posts) for every field.
</ResponseField>

<RequestExample>

```bash cURL
curl "https://admin.theteam.com.tn/api/blog-posts/power-bi-en-tunisie-transformer-vos-donnees-en-decisions" \
  -H "Accept: application/json"
```

```javascript JavaScript
const res = await fetch(`https://admin.theteam.com.tn/api/blog-posts/${encodeURIComponent(slug)}`, {
  headers: { Accept: "application/json", "X-Locale": "fr" },
});
if (res.status === 404) return notFound();
const { data: post } = await res.json();
```

</RequestExample>
