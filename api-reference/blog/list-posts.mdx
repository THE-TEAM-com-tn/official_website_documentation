---
title: "List blog posts"
sidebarTitle: "List posts"
description: "Paginated published blog posts, newest first, with search and a multi-category filter."
api: "GET /blog-posts"
---

Returns **published** posts (`status = true` and `published_at` set), ordered by `published_at`, newest
first. It powers the `/blogs` page. In the list, `content` is a **plain-text preview** (first three
non-empty lines, at most about 300 characters). Fetch [a single post](/api-reference/blog/get-post) for
the full HTML.

## Query parameters

<ParamField query="page" type="integer" default="1">
  Page number.
</ParamField>

<ParamField query="per_page" type="integer" default="15">
  Page size. Not clamped.
</ParamField>

<ParamField query="search" type="string">
  Case-insensitive match on the title and the content, both languages.
</ParamField>

<ParamField query="categories" type="string">
  Comma-separated category **slugs** (`pmp,scrum`). Returns posts in any of them. Slugs come from
  [List blog categories](/api-reference/blog/list-categories). Empty entries are ignored.
</ParamField>

<ParamField header="X-Locale" type="string" default="fr">
  `fr` or `en`.
</ParamField>

## Response

A Laravel API Resource collection: `data`, `links` and `meta`. See [Pagination](/concepts/pagination).
The pagination links do not carry your filters; add them back when you follow `links.next`.

<RequestExample>

```bash cURL
curl "https://admin.theteam.com.tn/api/blog-posts?per_page=6&categories=pmp,power-bi" \
  -H "Accept: application/json"
```

```javascript JavaScript
const params = new URLSearchParams({ per_page: "6", categories: ["pmp", "power-bi"].join(",") });
const res = await fetch(`https://admin.theteam.com.tn/api/blog-posts?${params}`, {
  headers: { Accept: "application/json", "X-Locale": "fr" },
});
const { data: posts, meta } = await res.json();
```

</RequestExample>
