---

Replaces the password of the authenticated account and emails it a **"Votre mot de passe a été
modifié"** notice (date, device, IP and a reset link). A failed notice email is logged and never blocks
the change. Existing tokens stay valid.

<ParamField header="Authorization" type="string" required>
  `Bearer <token>`.
</ParamField>

<ParamField body="current_password" type="string" required>
  The account's current password.
</ParamField>

<ParamField body="new_password" type="string" required>
  At least 6 characters.
</ParamField>

<ParamField body="new_password_confirmation" type="string" required>
  Must equal `new_password`.
</ParamField>

## Response

<ResponseField name="message" type="string" required>`Password updated.`</ResponseField>

<RequestExample>

```bash cURL
curl -X POST "https://admin.theteam.com.tn/api/password/update" \
  -H "Accept: application/json" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer $TOKEN" \
  -d '{"current_password": "old-password", "new_password": "new-password", "new_password_confirmation": "new-password"}'
```

```javascript JavaScript
await fetch("https://admin.theteam.com.tn/api/password/update", {
  method: "POST",
  headers: {
    Accept: "application/json",
    "Content-Type": "application/json",
    Authorization: `Bearer ${token}`,
  },
  body: JSON.stringify({
    current_password: "old-password",
    new_password: "new-password",
    new_password_confirmation: "new-password",
  }),
});
```

</RequestExample>

<ResponseExample>

```json 200
{
  "message": "Password updated."
}
```

```json 401
{
  "message": "Current password incorrect."
}
```

```json 422
{
  "message": "Le texte new password doit contenir au moins 6 caractères. (and 1 more error)",
  "errors": {
    "new_password": [
      "Le texte new password doit contenir au moins 6 caractères.",
      "Le champ de confirmation new password ne correspond pas."
    ]
  }
}
```

</ResponseExample>
