---
title: "Request a password reset"
sidebarTitle: "Forgot password"
description: "Email a password-reset link to a staff account."
api: "POST /password/forgot"
playground: "simple"
---

Sends a reset email through Laravel's password broker. The link opens the admin panel's reset page
(`https://admin.theteam.com.tn/admin/reset-password/{token}`). An API client can also take the token
from that link and call [Reset the password](/api-reference/auth/reset-password).

<Note>
  Any broker outcome other than "link sent" returns `500 Unable to send reset link.`
</Note>

<ParamField body="email" type="string" required>
  Account email address.
</ParamField>

## Response

<ResponseField name="message" type="string" required>`Reset link sent.`</ResponseField>

<RequestExample>

```bash cURL
curl -X POST "https://admin.theteam.com.tn/api/password/forgot" \
  -H "Accept: application/json" \
  -H "Content-Type: application/json" \
  -d '{"email": "staff@example.com"}'
```

```javascript JavaScript
await fetch("https://admin.theteam.com.tn/api/password/forgot", {
  method: "POST",
  headers: { Accept: "application/json", "Content-Type": "application/json" },
  body: JSON.stringify({ email: "staff@example.com" }),
});
```

</RequestExample>

<ResponseExample>

```json 200
{
  "message": "Reset link sent."
}
```

```json 500
{
  "message": "Unable to send reset link."
}
```

</ResponseExample>
