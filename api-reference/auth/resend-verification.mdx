---
title: "Resend the verification email"
sidebarTitle: "Resend verification"
description: "Send a new email-verification link to an unverified staff account."
api: "POST /email/resend"
playground: "simple"
---

<ParamField body="email" type="string" required>
  Account email address.
</ParamField>

## Response

<ResponseField name="message" type="string" required>`Verification email resent.`</ResponseField>

| Status | When |
| :-- | :-- |
| `400` | The address is already verified (`Already verified.`) |
| `404` | No account uses this address |
| `422` | `email` missing or malformed |

<RequestExample>

```bash cURL
curl -X POST "https://admin.theteam.com.tn/api/email/resend" \
  -H "Accept: application/json" \
  -H "Content-Type: application/json" \
  -d '{"email": "staff@example.com"}'
```

```javascript JavaScript
await fetch("https://admin.theteam.com.tn/api/email/resend", {
  method: "POST",
  headers: { Accept: "application/json", "Content-Type": "application/json" },
  body: JSON.stringify({ email: "staff@example.com" }),
});
```

</RequestExample>

<ResponseExample>

```json 200
{
  "message": "Verification email resent."
}
```

```json 400
{
  "message": "Already verified."
}
```

```json 404
{
  "message": "No query results for model [App\\Models\\User]."
}
```

</ResponseExample>
