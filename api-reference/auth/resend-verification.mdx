---
title: "Resend the verification email"
sidebarTitle: "Resend verification"
description: "Send a new email-verification link to an unverified staff account."
api: "POST /email/resend"
playground: "simple"
---

The answer is always the same `200`, whatever the address. Only an unverified staff account receives
an email.

Rate limit: **3 requests per 10 minutes**.

<ParamField body="email" type="string" required>
  Account email address.
</ParamField>

## Response

<ResponseField name="message" type="string" required>
  `If that address belongs to an unverified account, a verification email is on its way.`
</ResponseField>

<RequestExample>

```bash cURL
curl -X POST "https://admin.theteam.com.tn/api/email/resend" \
  -H "Accept: application/json" \
  -H "Content-Type: application/json" \
  -d '{"email": "staff@example.com"}'
```

```javascript JavaScript
await fetch("https://admin.theteam.com.tn/api/email/resend", {
  method: "POST",
  headers: { Accept: "application/json", "Content-Type": "application/json" },
  body: JSON.stringify({ email: "staff@example.com" }),
});
```

</RequestExample>

<ResponseExample>

```json 200
{
  "message": "If that address belongs to an unverified account, a verification email is on its way."
}
```

```json 422
{
  "message": "Le champ adresse e-mail est obligatoire.",
  "errors": {
    "email": ["Le champ adresse e-mail est obligatoire."]
  }
}
```

</ResponseExample>
