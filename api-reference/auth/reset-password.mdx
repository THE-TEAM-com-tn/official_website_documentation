Completes the [forgotten-password flow](/api-reference/auth/forgot-password). On success the account
receives the "password changed" notice email. Tokens issued before the reset stay valid; use
[Log out everywhere](/api-reference/auth/logout-all) if the account may be compromised.

Rate limit: **5 requests per minute**.

<ParamField body="token" type="string" required>
  The token from the reset link (its last path segment).
</ParamField>

<ParamField body="email" type="string" required>
  Account email address.
</ParamField>

<ParamField body="password" type="string" required>
  New password, at least 6 characters.
</ParamField>

<ParamField body="password_confirmation" type="string" required>
  Must equal `password`.
</ParamField>

## Response

<ResponseField name="message" type="string" required>`Password reset.`</ResponseField>

An invalid or expired token, or an email that does not match it, returns `500 Reset failed.`

<RequestExample>

```bash cURL
curl -X POST "https://admin.theteam.com.tn/api/password/reset" \
  -H "Accept: application/json" \
  -H "Content-Type: application/json" \
  -d '{"token": "token-from-the-email", "email": "staff@example.com", "password": "new-password", "password_confirmation": "new-password"}'
```

```javascript JavaScript
await fetch("https://admin.theteam.com.tn/api/password/reset", {
  method: "POST",
  headers: { Accept: "application/json", "Content-Type": "application/json" },
  body: JSON.stringify({
    token: "token-from-the-email",
    email: "staff@example.com",
    password: "new-password",
    password_confirmation: "new-password",
  }),
});
```

</RequestExample>

<ResponseExample>

```json 200
{
  "message": "Password reset."
}
```

```json 422
{
  "message": "Le texte mot de passe doit contenir au moins 6 caractères. (and 1 more error)",
  "errors": {
    "password": [
      "Le texte mot de passe doit contenir au moins 6 caractères.",
      "Le champ de confirmation mot de passe ne correspond pas."
    ]
  }
}
```

```json 500
{
  "message": "Reset failed."
}
```

</ResponseExample>
