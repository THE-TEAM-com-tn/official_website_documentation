---
title: "Verify an email address"
sidebarTitle: "Verify email"
description: "Mark a staff account's email address as verified from the emailed link."
api: "GET /email/verify/{id}/{hash}"
playground: "simple"
---

The verification email links here. Login is refused with `403 Email not verified` until this succeeds.
Accounts created from an invitation are already verified.

<ParamField path="id" type="integer" required>
  User id.
</ParamField>

<ParamField path="hash" type="string" required>
  SHA-1 hash of the account's email address, as written in the link.
</ParamField>

## Response

<ResponseField name="message" type="string" required>
  `Email verified.` or, when it was already done, `Already verified.`
</ResponseField>

<RequestExample>

```bash cURL
curl "https://admin.theteam.com.tn/api/email/verify/7/2f1d4f0c6c1a9e4b3d5e8f7a6b9c0d1e2f3a4b5c" \
  -H "Accept: application/json"
```

```javascript JavaScript
const res = await fetch(`https://admin.theteam.com.tn/api/email/verify/${id}/${hash}`, {
  headers: { Accept: "application/json" },
});
```

</RequestExample>

<ResponseExample>

```json 200
{
  "message": "Email verified."
}
```

```json 200 (again)
{
  "message": "Already verified."
}
```

```json 403
{
  "message": "Invalid verification link."
}
```

```json 404
{
  "message": "No query results for model [App\\Models\\User] 7"
}
```

</ResponseExample>
