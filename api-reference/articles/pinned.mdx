---
title: "List pinned articles"
sidebarTitle: "Pinned articles"
description: "Up to 10 pinned, published Knowledge Corner articles, newest first."
api: "GET /articles/pinned"
---

Returns the pinned articles that are published, newest first, without pagination. The admin panel caps
pins at **10**. Items use the same shape as [List articles](/api-reference/articles/list).

<ParamField header="X-Locale" type="string" default="fr">
  `fr` or `en`.
</ParamField>

## Response

<ResponseField name="data" type="object[]" required>
  Article objects without `content`.
</ResponseField>

<RequestExample>

```bash cURL
curl "https://admin.theteam.com.tn/api/articles/pinned" \
  -H "Accept: application/json"
```

```javascript JavaScript
const res = await fetch("https://admin.theteam.com.tn/api/articles/pinned", {
  headers: { Accept: "application/json" },
});
const { data: pinned } = await res.json();
```

</RequestExample>
