title: "Get an article"
sidebarTitle: "Get an article"
description: "One published Knowledge Corner article by slug, with its HTML content, its languages and up to three related articles."
api: "GET /articles/{slug}"
---

Returns a published article (`status` on and `published_at` reached) with its full HTML `content`.
Drafts, scheduled, deleted and unknown articles answer `404`.

The response adds two things to the [list shape](/api-reference/articles/list):

- `data.available_locales`: the languages that have a real title and body. The site points the canonical
  URL of an untranslated `/en/` page at the French URL.
- `related`: up to 3 other published articles, same category first, then the newest.

To share an article on social networks, use [`/share/article/{slug}`](/api-reference/web/share-article).

<ParamField path="slug" type="string" required>
  Article slug, the path of the article on the site.
</ParamField>

<ParamField header="X-Locale" type="string" default="fr">
  `fr` or `en`. Untranslated fields fall back to French.
</ParamField>

## Response

<ResponseField name="data" type="object" required>
  Article object as in [List articles](/api-reference/articles/list), plus:

  <Expandable title="extra fields" defaultOpen>
    <ResponseField name="content" type="string" required>Full HTML body.</ResponseField>
    <ResponseField name="available_locales" type="string[]" required>`["fr"]` or `["fr", "en"]`.</ResponseField>
  </Expandable>
</ResponseField>
<ResponseField name="related" type="object[]" required>
  Up to 3 article objects in the list shape (no `content`).
</ResponseField>

<RequestExample>

```bash cURL
curl "https://admin.theteam.com.tn/api/articles/certification-pmp-version-8" \
  -H "Accept: application/json" \
  -H "X-Locale: en"
```

```javascript JavaScript
const res = await fetch(`https://admin.theteam.com.tn/api/articles/${encodeURIComponent(slug)}`, {
  headers: { Accept: "application/json", "X-Locale": "en" },
});
if (res.status === 404) return notFound();
const { data: article, related } = await res.json();
```

</RequestExample>
