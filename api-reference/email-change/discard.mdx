---
title: "Discard the pending email change"
sidebarTitle: "Discard pending change"
description: "Drop the account's own pending email change without signing anything out."
api: "DELETE /email/change"
authMethod: "bearer"
playground: "simple"
---

Deletes the pending request, if any. Unlike [cancelling from the old address](/api-reference/email-change/cancel),
this does **not** revoke tokens or sessions: it is the account owner changing their mind. The answer is
the same when nothing was pending.

<ParamField header="Authorization" type="string" required>
  `Bearer <token>`.
</ParamField>

## Response

<ResponseField name="message" type="string" required>`Changement d’adresse e-mail annulé.`</ResponseField>

<RequestExample>

```bash cURL
curl -X DELETE "https://admin.theteam.com.tn/api/email/change" \
  -H "Accept: application/json" \
  -H "Authorization: Bearer $TOKEN"
```

```javascript JavaScript
await fetch("https://admin.theteam.com.tn/api/email/change", {
  method: "DELETE",
  headers: { Accept: "application/json", Authorization: `Bearer ${token}` },
});
```

</RequestExample>

<ResponseExample>

```json 200
{
  "message": "Changement d’adresse e-mail annulé."
}
```

</ResponseExample>
